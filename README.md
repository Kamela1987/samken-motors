# SamKen Motors

Static site deployed to GitHub Pages via .github/workflows/pages.yml (push to main).

- index.html: page
- styles.css: styles
- script.js: nav, vehicle cards, tracker
- vehicles.js: vehicle list (edit here to add or change vehicles)
- data/tracking.json, data/shipments.json: tracking and port data
- images/: photos (keep this folder in the repo)
